# 离线模型使用说明

1. 打开 Android“我的 → AI 运行方式”。
2. 选择“本地模型”。未下载时页面会显示 Qwen3.5-2B、版本、约 1.29 GiB 下载量、当前占用和兼容性。
3. 默认仅 Wi-Fi。关闭限制前会再次确认移动流量风险。
4. 点击“下载离线模型”。真实进度来自已写入字节；可暂停、继续，网络中断或关闭应用后由 WorkManager 恢复。
5. 下载后会逐文件 SHA-256 校验；只有全部通过才显示 Ready。
6. AI 页顶部用 `DeepSeek / 本地模型` 两段按钮切换。选择本地模型时固定 FAST；DeepSeek 才提供 FAST/DEEP。今日/周/月总结、课程整理和“解析记录”收在“快捷任务”底部抽屉中。
7. 删除时使用滑动确认。应用先取消推理、释放 MNN 文件句柄，再删除私有模型目录；聊天报告保留。
8. Ready 后可点“重新下载”并滑动确认；应用会先安全停止下载/推理、删除旧文件，再按当前 Wi-Fi 设置重新开始，避免同时保留两份大模型。

## 使用自己的 DeepSeek Key

1. 打开“我的 → AI 运行方式”，在“DeepSeek 个人 Key”中粘贴自己的 Key 并点“安全保存 Key”。
2. Key 使用 Android Keystore 加密并排除备份；应用不显示完整已保存值，只显示首尾掩码。
3. 选择“自动”时，在线使用自己的 Key，离线且模型 Ready 时使用本地；选择“DeepSeek · 我的 Key”时固定联网使用自己的 Key。
4. 没有 Key、Key 无效或余额不足时会明确报错，不会调用 CampusAI 平台额度。可删除或替换 Key。

旧版本保存的 AUTO 在进入新版 AI 对话页时迁移为显式 DeepSeek 选择；LOCAL 不会自动切云端。本地失败时只有点击“本次使用我的 DeepSeek Key”才会发送。

本地模型若尝试输出 Thinking Process、系统提示或内部 JSON，CampusAI 会在进入聊天气泡前拦截，并要求重试或显式切换 DeepSeek；这些内部内容不会显示在页面中。

## 注册

登录页切换到“注册”，输入邮箱、密码和确认密码即可。项目已关闭邮箱确认，注册成功后直接登录；界面没有验证码步骤。Web 管理台不开放管理员自助注册。
