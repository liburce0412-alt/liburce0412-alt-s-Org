# Caesar∞ v2.0.1

`v2.0.1` 是 V2 的个人资料恢复补丁。`v2.0.0` 的 GitHub Release 在构建时误用了 Supabase 匿名客户端配置的占位值，因此覆盖安装后本地行动、登录令牌和设置仍然存在，但昵称、头像、封面等云端资料无法读取。

## 修复内容

- Release 工作流现在必须取得有效的 `SUPABASE_URL` 与 `SUPABASE_ANON_KEY`，缺失、非 HTTPS 或仍为占位值时立即停止发布。
- 构建前只在临时工作区恢复公共 Supabase 客户端配置；打包后验证配置确实进入签名 APK，并在工作流结束时删除临时文件。
- 启动时先刷新保留的登录会话，再读取个人资料；周期刷新令牌成功后也会重新读取资料，避免旧 access token 与资料请求并发导致头像停在默认状态。
- 头像与封面加载期间或失败时保留 Caesar∞ 品牌回退，不再出现空圆环、空封面或低对比文字。

V2 的 Mi Fitness、Agent Provider、健康自动化、本地多模态和 SPECTRA 功能保持不变，完整功能说明参见 [`v2.0.0`](v2.0.0.md)。

## 下载与校验

正式发布包含：

- `caesar-v2.0.1.apk`：Caesar∞ Android 主应用；
- `SHA256SUMS.txt`：APK 的 SHA-256。

本补丁继续沿用 V2 当前签名证书，可直接覆盖 `v2.0.0`，不会清除登录状态、本地模型、历史会话或行动记录。签名证书 SHA-256：`D8:3C:2C:C6:86:A2:39:CD:2F:3A:A6:D5:CD:F6:F9:01:92:7F:93:77:16:A5:AE:47:E1:8B:B2:30:51:AA:BF:14`。
