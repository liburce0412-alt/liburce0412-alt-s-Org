# Caesar∞ v1.0.0

`v1.0.0` 是 Caesar∞ 的首个正式源码版本，建立了端侧多模态 Agent、App 工具闭环、个人记忆、健康感知和 SPECTRA 原生界面的共同基线。

## 发布内容

- Qwen3.5-2B FAST 与 Qwen3.5-4B DEEP 可独立下载、校验和删除，并按会话锁定模型。
- 本地文字、图片、拍照、OCR 辅助、语音输入和 TTS 进入同一个 Agent Runtime。
- 类型化工具支持参数校验、风险分级、确认、幂等、取消、恢复和动态结果卡片。
- 严格本地输出守卫处理 UTF-8 流、私有推理标记和工具传输协议。
- 长期记忆采用先提议、后确认的可编辑模型；原始健康序列不写入记忆。
- Health Connect、首页健康摘要和 Caesar 健康工具完成接入。
- 独立 CaesarBandBridge 提供签名保护状态 IPC、Gadgetbridge 同步触发和诊断。
- SPECTRA 全局流体环境、OpticalGlass 与 CaesarSurface 形成统一原生界面。
- 树洞、心愿墙和个人页完成私人应用语义收口；个人页不再包含订单入口。
- Supabase 与用户主动选择的 DeepSeek 构成 V1 的受控联网边界。

## 下载与校验

正式 APK 只有在仓库配置 Android 发布签名后才会附加到 GitHub Release：

- `caesar-v1.0.0.apk`：主应用；
- `caesar-bandbridge-v1.0.0.apk`：Band 伴侣；
- `SHA256SUMS.txt`：两个安装包的 SHA-256。

如果 Release 页面没有这些文件，本次发布就是源码发布。请从标签源码自行构建，不要安装第三方重打包 APK，也不要用仓库中的 debug keystore 作为公开发布身份。

主应用与 Band Bridge 必须由同一发布证书签名，否则签名级 IPC 会拒绝连接。正式签名 APK 也不能覆盖已有的 debug 签名安装；迁移前请先备份可导出的本地数据，且不要为了安装 Release 擅自清除当前个人环境。

## 已知边界

- 主要真机基线为 Xiaomi 15 Pro、Android 16、16 GB RAM。
- Band 9 私有协议与 Gadgetbridge 的历史解析会随固件变化；Health Connect 是稳定历史数据边界。
- V1 没有通用网页搜索或任意 URL 浏览工具。
- Caesar∞ 不提供医疗诊断，不会把缺失健康数据伪造成测量结果。
- 模型权重、个人密钥、配对材料、健康原始序列和设备日志不包含在源码或 Release 中。
- 当前仓库未附加开源许可证，默认保留所有权利。
